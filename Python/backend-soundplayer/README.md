# プログラムの起動方法

## uvについて

uvとはPythonの仮想環境のパッケージ管理アプリである。
このプログラムはuvでパッケージの管理をしているので、uvを推奨する。

## uvのインストール

Pythonはインストールされているものとする。

```sh
pip install uv
```

## uvで実行する前にやること

```sh
uv sync
```

これで依存関係をインストールする。

## uvの実行

Code Runnerを使う場合はこのままボタンから実行可能。

ターミナルで実行する場合は

```sh
uv run python [実行するファイル名]
```

で実行する。
